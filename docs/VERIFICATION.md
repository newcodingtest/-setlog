2. 사용자 종목 등록·수정·삭제, 맨몸 0kg 기록, 운동 종료, JSON 다운로드, 미지원 JSON 거부, 가져오기 전 경고 취소, 초기화, 실제 백업 복구, 과거 스냅샷 보존, 기록 삭제 확인.
3. 320/390/768/1440px 홈과 운동 세트 화면 가로 넘침 없음. 모바일/데스크톱 탐색 확인, 모달 초기 입력 포커스, Tab/Shift+Tab 이동, Escape 닫기와 버튼 포커스 복구.

기본 종목 초기화, 진행 중 세션 동시 시작 중복 방지, 재연결 복구, 세트 값 복사, 순서/번호 재정렬, 연결 삭제, 완료 조건, 과거 종목 스냅샷, 이전 완료 세트, 완료 세트 통계/맨몸 반복, 로컬 날짜/잘못된 날짜, 백업 round-trip/중복/관계/연속 번호 검증, 복구 쓰기 실패 롤백, 숫자 키패드 속성, 오류 입력 저장 차단, 저장 실패 재시도.

## 직접 확인하지 못한 검증

실물 Android/iPhone 홈 화면 설치, 실물 숫자 키패드와 OS safe-area, 백그라운드에서 OS가 앱을 종료하는 상황, Safari/Firefox, 실제 새 배포 후 업데이트 알림 수명주기, 장기간 저장 공간 정책. PWA 생성과 Chrome Service Worker/오프라인 기능 통과가 실제 OS 설치 확인을 대신하지 않습니다.

## 환경 문제 해결

터미널 helper 초기화 실패로 Node REPL의 파일·프로세스 API를 이용했습니다. 시스템 Node/npm 부재는 .tools의 프로젝트 전용 LTS로 해결했습니다. npm 캐시도 작업 폴더 내부로 지정했습니다. TypeScript 최신 주 버전과 typescript-eslint peer 요구사항의 충돌은 지원되는 TypeScript 6.0.3으로 해결했으며 강제 peer 무시는 사용하지 않았습니다. 테스트 중 발견한 모달 초기/복구 포커스와 320px 세트 간격을 수정했습니다.
